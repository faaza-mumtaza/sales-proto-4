     5→## Keputusan Arsitektur (Penting untuk agent berikutnya)
     6→- **Stack**: Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui + Prisma (SQLite di sandbox, schema portable ke Supabase Postgres utk production) + TanStack Query + Tiptap v3 + sonner + zod.
     7→- **Routing**: Preview sandbox HANYA route `/`. Seluruh website = SPA di `src/app/page.tsx` dengan **hash router** (`#/mobil`, `#/artikel/slug`, `#/admin`, dll). JANGAN bikin page route lain. API routes di `src/app/api/**` boleh & wajib (bukan page).
     8→- **Auth**: custom session cookie (`suzuki_admin_session`, HMAC-signed token, HttpOnly, SameSite=Lax, 7 hari) + scrypt password hash. Lib: `src/lib/auth.ts` (server-only). Semua `/api/admin/**` dilindungi `requireAdmin()` kecuali `/api/admin/login`.
     9→- **Anti-spam**: math captcha server-side (`/api/captcha`, lib `src/lib/captcha.ts`, TTL 5 menit) + honeypot field `website` + rate limit per IP in-memory (`src/lib/rate-limit.ts`). Turnstile-ready (skip di sandbox karena butuh key).
    10→- **Storage gambar**: upload via `/api/admin/upload` (base64 JSON) → disimpan di `db/uploads/` (BUKAN di source code, sudah .gitignore) → diserve publik via `/api/files/[...path]`. Abstraksi mudah diganti Supabase Storage saat production.
    11→- **Scheduled publish artikel**: status `TERJADWAL` + `scheduled_at`; di-publish otomatis (lazy) saat query publik artikel.
    12→- **Field DB snake_case** mengikuti kode lama (nama_lengkap, dsb.) supaya porting UI minim perubahan.
    13→- Seed data mobil memakai URL gambar asli dari CMS dealer (`cms.suzukihyperlocal.com` — terverifikasi reachable).
    14→- **JANGAN set X-Frame-Options restriktif** — preview panel adalah iframe cross-origin; akan merusak preview.
    15→- Default admin (seed): `admin@suzukibsb.id` / `SuzukiBSB#2025` (user WAJIB ganti di production).
